# 설계 결정 기록

## D1. 궤도 크기는 장반경 a 대신 반통경 p로 저장 (1단계)
- a는 포물선에서 무한대, 쌍곡선에서 음수가 되어 한 타입으로 다루기 불편하다.
- p는 모든 원뿔곡선에서 양의 유한값이다. a는 `Elements.a` 속성으로 계산해 제공한다.

## D2. 특이 궤도의 각도 규약 (1단계)
- 적도 궤도(i ≈ 0, π): raan = 0, 기준축은 관성 x축.
- 원 궤도(e ≈ 0): argp = 0, ν는 승교점(적도 궤도면 x축)부터 잰다.
- Vallado의 진경도·위도인수 개념을 별도 필드 없이 기존 6요소에 담는 방식이다.
  `coe_to_rv(rv_to_coe(r, v))`가 특이 궤도에서도 항등이 되는 것을 테스트로 보장한다.
- 판정 허용오차는 무차원 1e-11 (`CIRCULAR_TOL`, `EQUATORIAL_TOL`).

## D3. core 함수는 스칼라 `math` 기반 (1단계)
- 케플러 방정식·근점이각 변환은 스칼라 float를 받는다. 전파 루프 안에서 호출되므로
  numpy 배열 오버헤드를 피하고 코드를 교과서 공식에 가깝게 유지한다.
- 벡터화가 필요해지면 (예: 궤도 그림용 대량 샘플링) 별도 함수로 추가한다.

## D4. 포물선의 평균근점이각은 Barker 방정식 M = D + D³/3 (1단계)
- `mean_to_true`/`true_to_mean`이 이심률만으로 세 궤도 종류를 자동 처리하도록 하기 위함.
