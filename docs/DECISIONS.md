# 설계 결정 기록

## D1. 궤도 크기는 장반경 a 대신 반통경 p로 저장 (1단계)
- a는 포물선에서 무한대, 쌍곡선에서 음수가 되어 한 타입으로 다루기 불편하다.
- p는 모든 원뿔곡선에서 양의 유한값이다. a는 `Elements.a` 속성으로 계산해 제공한다.

## D2. 특이 궤도의 각도 규약 (1단계)
- 적도 궤도(i ≈ 0, π): raan = 0, 기준축은 관성 x축.
- 원 궤도(e ≈ 0): argp = 0, ν는 승교점(적도 궤도면 x축)부터 잰다.
- Vallado의 진경도·위도인수 개념을 별도 필드 없이 기존 6요소에 담는 방식이다.
  `coe_to_rv(rv_to_coe(r, v))`가 특이 궤도에서도 항등이 되는 것을 테스트로 보장한다.
- 판정 허용오차는 무차원 1e-11 (`CIRCULAR_TOL`, `EQUATORIAL_TOL`).

## D3. core 함수는 스칼라 `math` 기반 (1단계)
- 케플러 방정식·근점이각 변환은 스칼라 float를 받는다. 전파 루프 안에서 호출되므로
  numpy 배열 오버헤드를 피하고 코드를 교과서 공식에 가깝게 유지한다.
- 벡터화가 필요해지면 (예: 궤도 그림용 대량 샘플링) 별도 함수로 추가한다.

## D4. 포물선의 평균근점이각은 Barker 방정식 M = D + D³/3 (1단계)
- `mean_to_true`/`true_to_mean`이 이심률만으로 세 궤도 종류를 자동 처리하도록 하기 위함.

## D5. 단위 라이브러리는 astropy (2단계)
- MVP 이후 UTC/TAI/TDB 변환이 필요한데 `astropy.time`이 이를 제공한다. pint를 쓰면 시간 척도를 따로 구현해야 한다.
- 천문·우주 분야의 사실상 표준이라 대상 사용자가 이미 익숙할 가능성이 높다.
- 단점(설치 크기, Quantity 연산 오버헤드)은 단위 변환을 경계(`units.py`)에서만 하므로 계산 성능에 영향이 없다.

## D6. 맨 숫자는 SI로 간주, 각도 포함 (2단계)
- `to_si(30, ANGLE)`는 30 rad이다. 도 단위는 `30 * u.deg`로 명시해야 한다.
- 각도만 예외로 두면 규칙이 두 개가 되어 실수가 더 늘어난다고 판단했다.

## D7. 시간은 J2000 기준 TDB 경과 초 하나의 float64 (2단계)
- `Epoch(tdb_seconds)`로 캡슐화. 2000~2100년 범위에서 float64 정밀도는 약 1e-7 s로,
  LEO 속도(7.8 km/s)에서 1 mm 미만의 위치 오차라 MVP 정확도 목표에 충분하다.
- 달력·JD 입력은 TDB로 해석한다. TDB 달력은 윤초가 없어 단순 날짜 차이가 정확하다.
- 다른 시간 척도는 `Epoch.from_astropy()`를 거치면 astropy가 변환한다. 자체 변환은 구현하지 않는다.

## D8. Body는 질량 대신 μ(GM)를 저장 (3단계)
- μ는 궤도 관측으로 직접 결정되어 G·M 각각보다 수십만 배 정확하다 (G 자체의 불확도가 약 2e-5).
- 질량은 `Body.mass = μ/G` 속성으로 제공한다. 각 프리셋에 `source`로 상수 출처를 남긴다.

## D9. Orbit의 기준 상태는 상태벡터 (r, v, epoch) (3단계)
- 상태벡터는 원·적도·포물선 궤도에서도 특이점이 없고, 전파기의 입출력 형식과 같다.
- 궤도 요소는 `cached_property`로 한 번만 계산해 둔다. 객체가 불변이라 캐시가 무효화될 일이 없다.
- r, v는 복사 후 읽기 전용 배열로 저장한다. numpy 배열은 값 비교가 모호하므로 `eq=False`(동일성 비교).

## D10. 궤도 프리셋 ISS는 Orbit 객체 (3단계)
- SPEC의 `ISS.orbit.transfer_to(GEO)` 예시는 우주선 객체를 암시하지만, 우주선 객체는 MVP 범위에 없다.
  프리셋 목록(LEO, ISS, GEO, SSO)이 궤도로 분류되어 있어 `ISS.transfer_to(GEO)` 형태로 정했다.
- 프리셋은 대표값이다 (ISS: 420 km 원 궤도, 51.64°). 실제 위치는 TLE로 얻는다.
- GEO 반지름은 지구 자전 각속도로부터, SSO 경사각은 J2 승교점 변화율로부터 계산한다.
